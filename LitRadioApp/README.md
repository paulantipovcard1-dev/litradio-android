# LitRadio — Android-плеер (MVP)

Минимальное приложение: кнопка play/pause + название текущего трека
(обновляется автоматически из ICY-метаданных потока, как в веб-плеере
на сайте).

## Как собрать APK

1. Установи **Android Studio** (бесплатно, [developer.android.com/studio](https://developer.android.com/studio)).
2. File → Open → выбери эту папку (`LitRadioApp`).
3. Дай Android Studio скачать нужные зависимости (гугловские
   репозитории Gradle) — при первом открытии это займёт пару минут,
   нужен интернет.
4. Build → Build Bundle(s)/APK(s) → Build APK(s).
5. Готовый файл появится в
   `app/build/outputs/apk/debug/app-debug.apk` — его можно установить
   на телефон напрямую (либо через USB-кабель и `adb install`, либо
   просто скопировав файл на телефон и открыв).

## Что уже настроено

- Поток: `https://litradio.link/radio.mp3`
- Плеер: ExoPlayer (Media3) — умеет напрямую читать ICY title из
  Icecast-потока, название трека обновляется в реальном времени.
- Минимальная версия Android: 6.0 (API 23).

## Фоновое воспроизведение

Реализовано через `MediaSessionService` (Media3) — при сворачивании
приложения поток продолжает играть, в шторке появляется уведомление
с play/pause и названием трека, управление доступно и с экрана
блокировки. На Android 13+ при первом запуске система спросит
разрешение на уведомления — без него сама музыка играет, но
уведомление не покажется.

## Что можно добавить дальше (не реализовано в этой версии)

- **Экран статистики** (страны/уники) — можно подключить тот же
  `/root/radio_stats.py`, обернув его в простой HTTP JSON-эндпоинт на
  сервере, и показывать в отдельной вкладке приложения.
- **Публикация в Google Play** — нужен аккаунт разработчика
  ($25 разовый взнос), подписанный release-билд, скриншоты и
  описание.
- **Логотип/иконка** — сейчас используется стандартная системная,
  свою иконку можно добавить через Android Studio →
  Image Asset Studio.
